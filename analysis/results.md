## 4. Simulated click feedback (residual collection)

The simulated user reads BM25's top 5: grade 2 → long read (relevant), otherwise → quick return (not relevant). Rocchio then re-ranks; the 5 seen documents are removed from both rankings before scoring.

| | nDCG@10 (unjudged = not relevant) | judged in top 10 | nDCG@10 condensed (unjudged removed) |
|---|---|---|---|
| BM25, no feedback | 0.752 | 84% | 0.838 |
| BM25 + click feedback | 0.675 | 74% | 0.844 |

p = 0.004 (unjudged = not relevant); p = 0.717 (condensed). Feedback surfaces more documents outside the judged pool, so the first column is biased against it; the condensed column removes that bias.
